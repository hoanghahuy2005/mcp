Glossaire¶

Action¶

Les réserves sont utilisées en prévision des risques. Elles permettent de réduire les risques.

L’analyse de ces risques consiste à définir des actions. Il existe deux types d’actions :L’analyse de ces risques consiste à définir des actions. Il existe deux types d’actions :

  • Action préventive visant à supprimer le risque, ou

  • Action corrective mise en œuvre lors de la survenance d’un risque

Activité¶

Une Activité peut être assimilée aux étapes clés du projet : c’est le squelette de votre projet qui organise les phases principales d’un projetUne Activité peut être assimilée aux étapes clés du projet : c’est le squelette de votre projet qui organise les principales phases d’un projet

  • Elles ont une date de début et une date de fin

  • Elles sont conçues pour les phases de planification d’un projet

  • Elles permettent d’organiser les jalons et les tâches d’un projet

  • Elles peuvent être affectées à une ou plusieurs ressources

  • Elles peuvent être hiérarchisées et comporter des sous-activités

Id¶

  • L’Id est attribué de manière chronologique, pour tous les types d’éléments (Activité, Ticket).

Indispensable au chef de projet, un indicateur permet d’évaluer une situation et de prendre une décision adaptée. Les indicateurs clés de performance mesurent la performance de vos projets. Vous les choisissez avec votre équipe. Ils doivent être simples, fiables, facilement compréhensibles par tous et pertinentsIndispensable au chef de projet, un indicateur permet d’évaluer une situation et de prendre une décision adaptée. Les indicateurs clés de performance mesurent la performance de vos projets. Vous les choisissez conjointement avec votre équipe. Ils doivent être simples, fiables, facilement compréhensibles par tous et pertinents

Si l’indicateur est vert, tout va bien, vous devrez continuer les actions en cours pour maintenir ce bon résultat. Si l’indicateur est rouge, vous devez prendre les mesures correctives nécessaires. Si l’indicateur est orange, il doit être surveillé.Si l’indicateur est vert, tout va bien, vous devrez poursuivre les actions en cours pour maintenir ce bon résultat. Objectif¶

Un objectif est un but à atteindre en réalisant différentes tâches. Par exemple, construire une nouvelle usine afin de produire davantage et répondre à la demande croissante. Il est essentiel de définir précisément le ou les buts à atteindre pour que vous et votre équipe sachiez où vous allez. Un bon objectif doit être SMART.Un objectif est un but à atteindre en accomplissant différentes tâches. Par exemple, construire une nouvelle usine afin de produire davantage et répondre à la demande croissante. Il est essentiel de définir précisément le ou les buts à atteindre afin que vous et votre équipe sachiez où vous allez. Un bon objectif doit être SMART.
