Gestion des plug-ins¶

Les plugins sont des compléments pour l’application ProjeQtOr.

Ils ajoutent des fonctionnalités non génériques à ProjeQtOr

Vous trouverez la liste complète des plugins dans le magasin en ligne ProjeQtOr

Installation des plug-ins

La section Plugins installés liste les plug-ins installés.

Liste des plug-ins disponibles

La section Plugins disponibles permet de gérer les plug-ins locaux

  • Le bouton Parcourir permet de sélectionner le fichier plugin .zip.

  • Le fichier sera téléchargé et il sera ajouté dans la liste des plugins.

  • Cliquez sur pour installer le plug-in.

  • Cliquez sur pour afficher la description du plug-in.

  • Cliquez sur pour supprimer le plugin de la table d’installation.

  • Le plug-in sera déployé lors de l’installation.

  • Le résultat du déploiement sera disponible dans le fichier log (Voir : Console d’Administration).

  • Le plug-in est supprimé de la liste après l’installation.
