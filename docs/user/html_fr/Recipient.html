Destinataires de facturation¶

Le destinataire est le bénéficiaire des paiements de factures.

Les destinataires sont principalement définis pour stocker les informations de facturation.

Section Description

Champs obligatoires ¶

Champ

Description

Id

Identifiant unique pour le destinataire.

Nom

Nom abrégé du destinataire.

Numéro d’entreprise

Numéro d’entreprise, à afficher sur la facture.

Mentions légales

Mentions légales pour le destinataire.

Numéro de taxe

Numéro de référence fiscal, à afficher sur la facture.

Exonéré de taxe

Indicateur pour signaler que la taxe est automatiquement définie à zéro pour ce destinataire.

Nom du contact

Nom du contact pour le destinataire.

E-mail du contact

E-mail du contact pour le destinataire.

Téléphone du contact

Téléphone du contact pour le destinataire.

Clos

Indicateur pour signaler que le destinataire est archivé.

Section Numéro de compte bancaire international

Champ

Description

Banque

Nom de la banque.

Numéro international (IBAN)

IBAN pour le destinataire.

Code banque (BIC)

BIC pour le destinataire.

Numéro de compte national

Numéro de compte complet définissant le code de compte BBAN.

Section Adresse

Adresse complète du destinataire.
